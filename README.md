# Java Conditional Admission Project

A beginner-friendly Java console project demonstrating:
- `if-else` conditions
- Nested conditions
- `Scanner` input
- Marks and age eligibility
- Category-based fee selection
- Aadhaar number length validation
- UPI/Cash payment choice

## Run

```bash
javac -d out src/Java_Project_On_Conditional_Sta/First_Project.java
java -cp out Java_Project_On_Conditional_Sta.First_Project
```
